What the results mean

  • No model is meaningfully profitable yet. The best, ORB breakout, made +0.71% in one month with a 14% win rate.
  • At full scale the RL agent learned not to trade. With more training it trades, but loses slightly.
  • The zone, price-action and regime features haven't been added yet. These numbers are the bar to beat.
  • One test month is too small. Profit has to hold across many out-of-sample months, and across several training seeds.

Where we're ahead

Stricter leakage testing than most peers, realistic costs, and every model compared with simple baselines through one shared simulator.

Where we're behind

One instrument (SPY), a single training seed, no paper trading yet, and no standard performance report.

Biggest lesson

The strongest published intraday result, ORB, comes mostly from choosing which stocks to trade each day, not from the entry rule itself. That's now on our roadmap.

Goals & objectives

1. Maximum profit

The top priority: the highest net profit after costs, measured on out-of-sample months the model wasn't trained on.

2. Higher win rate

Among models with similar profit, prefer the one that wins more often.

3. Reasonable trade count

Enough trades for the result to be trustworthy and practical, without overtrading.

Approach

Central hypothesis

A zone-aware, price-action-driven, regime-conditioned RL system with specialized entry and an unrestricted exit policy may generalize better than an RL system trained directly on raw bars.

This is the approach being tested to reach the goal. Profit only counts if it holds on data the model was never trained on.

Current methods

  1. Simulator first: a trading environment with an external risk layer and realistic costs.
  2. Leakage control: tests change future bars and prove past features don't move.
  3. Baselines: 6 rule-based strategies through the same engine.
  4. RL agent: PyTorch PPO, one trading day per episode.
  5. Tracking: every run logged with parameters, seeds, code and data versions.

Main challenges

  • Blocker At full scale, too few iterations and sparse reward make PPO default to "do nothing".
  • Compute About 3 minutes per PPO iteration; full runs need checkpointed resumes.
  • Universe SPY alone may not offer enough intraday edge; selection across stocks is untested.
  • Reproducibility The diagnostic run wasn't logged and must be re-run.

Lessons learned

Run a small, fast diagnostic before any full-scale training run. It shows the same failure modes far more cheaply.

Log every run at the moment it's run. A result that exists only in a report can't be reproduced.

RL results vary a lot between random seeds. Reporting only the best seed overstates performance.

Compare against the published version of a strategy, not a textbook version. The details, like stock selection and stops, carry the edge.
