Project 6: Home Dashboard

An 11-page research platform for buying investment homes in Sacramento CA, Austin/Round Rock TX and Phoenix AZ. Each layer answers one question about a property: does it clear the buy bar, what it would earn, what it's worth, what the law allows, what the rehab costs, how risky it is, and who should manage it. A hub ties them together into a per-address dossier.

Where we're ahead

Breadth in one place: no commercial tool found combines comps, regulations, renovation, risk and property managers. Every number is traceable to the page it came from.

Where we're behind

Scale and freshness: about 40 subjects vs. national coverage, no measured valuation error rate, and no financing or IRR model yet.

Biggest lesson

Depth catches what automated scores miss: the wrong STR jurisdiction in a source thread, a stale investment score, an unanswered BBB complaint.

Approach

How each layer is built

  1. One question per layer, each a standalone page with an "At a glance" box: goal, summary, inputs, outputs.
  2. Primary sources first: county parcel viewers, ordinance text, license lookups, each listing's own price history.
  3. Every comp read individually, with methodology notes and flagged deviations.
  4. Queue-based growth: type an address on any layer and it's researched and added.
  5. Daily 7am search adds new listings that clear the buy criteria.

Next steps

Added from the benchmark review

  1. Financing & IRR scenarios in Layer 1.
  2. Measure our own valuation error against eventual sale prices.
  3. STR cross-check against a free AirDNA estimate.
  4. Daily status sync across all layers.
  5. Refresh the hub's Property Dossier (still at its Sep 5 snapshot).

Main challenges

  • Freshness Listing statuses change faster than manual sweeps.
  • Sample size 3–4 STR comps per subject is thin next to AirDNA's history.
  • Sites Some listing sites block automated reading, which forces fallback methods (flagged on each page).
